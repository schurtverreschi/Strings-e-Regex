# Praticando Python
Arquivo utilizado para organizar as atividades praticas do curso de pratica da Alura
## Objetivo:
Revisar e reforçar os conhecimentos aprendidos de strings e regex
## Atividades:
- tratamento_nome: Realiza a higienização de strings fornecidas pelo usuário (removendo espaços extras e formatando as iniciais em maiúsculas) e exibe o resultado;
- saudação_personalizada: Realiza a higienização de strings fornecidas pelo usuário (removendo espaços extras e formatando as iniciais em maiúsculas) e exibe numa f-string customizada para saudação;
- gerador_dicas: Utiliza fatiamento para cortar trechos específicos da palavra fornecida e devolver formatado para o usuário;
- verificador_link: Utiliza métodos starts with e ends with para verificar se o começo e o final da string são compatíveis com o formato de url aceito;
- filtro_numero: Utiliza de regex para identificar e coletar dígitos dentro do texto e devolver somente a numeração;
- troca_palavra: Utiliza função replace para alterar palavras especificas dentro do texto e retornar o texto corrigido;
- validador_nome: Realiza conferencia do nome inserido utilizando função full match do regex para verificar se o nome atende as especificações (primeira letra maiúscula e somente letras);
- validador_cpf: Confere se o formato inserido confere com o formato padrão de CPF através de regex
- busca_palavra: Utiliza regex para identificar e buscar palavras num texto a partir da inicial
